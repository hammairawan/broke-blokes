# Broke Blokes

IICT student project by Hammair & Ali Zuberi. A student finance education website for budgeting, saving and earning.

## How to open
Extract the ZIP and open index.html in a browser. No installation, server or internet connection is required.

## Pages
- `index.html` — Home
- `interactive.html` — Predictor
- `explore.html` — Tips
- `details.html` — Hustles
- `literacy.html` — Glossary
- `quiz.html` — Quiz
- `contact.html` — Contact

## JavaScript features
- Broke-O-Meter: budget coverage, shortfall and safe daily spending.
- Saving tips filter and equal/item-based bill splitter.
- Side hustle filter by hours and work style.
- Searchable financial glossary and eight-question quiz.
- Mobile navigation and contact form validation using submit and preventDefault().

The contact form is a local demo; it does not send or store messages. Images are local SVG illustrations. CSS and JavaScript are shared by all seven pages.

## Privacy guardrail
The contact form validates fictional demo details locally. No personal data is sent, saved or collected by a backend. Bill entries remain in page memory only. Do not enter real personal or financial information.

Side hustle risk levels are illustrative; verify employers and costs independently.
